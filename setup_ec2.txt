2) Crear imagen local
- docker build -t <dockerhub_username>/<image_name>:<tag> .
- crear deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: myapp
spec:
  replicas: 1
  selector:
    matchLabels:
      app: myapp
  template:
    metadata:
      labels:
        app: myapp
    spec:
      containers:
      - name: myapp
        image: <dockerhub_username>/<image_name>:<tag>
        ports:
        - containerPort: 80
- kubectl apply -f deployment.yaml
- crear service.yaml
apiVersion: v1
kind: Service
metadata:
  name: myapp-service
spec:
  selector:
    app: myapp
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
  type: LoadBalancer
- kubectl apply -f service.yaml
- minikube service myapp-service --url

######### CONFIGURAR NGINX ###########
- sudo apt install nginx

2 opciones:

	1)
		- sudo nano /etc/nginx/sites-available/fastapi-backend -> Crear archivo config nginx para proyecto fastapi_backend
			server{
				server_name <ip>; # IP drople
					location / {
					   include proxy_params;
					   proxy_pass http://127.0.0.1:8000;
					}
			}

		- sudo ln -s /etc/nginx/sites-available/fastapi-backend /etc/nginx/sites-enabled/fastapi-backend -> Crear enlace simbolico
	2)
		- sudo nano /etc/nginx/sites-enabled/fastapi-backend
		server{
				listen 80;
				server_name <ip>;
				location / {
						proxy_pass http://127.0.0.1:8000;
				}
		}
		
	3) (usada actualmente) 
		- sudo nano /etc/nginx/sites-available/artificial-teacher-backend -> Crear archivo config nginx para proyecto fastapi_backend
		- Añadir siguiente config:
		server{
			server_name artificial-teacher.pro www.artificial-teacher.pro;
			location / {
				include proxy_params;
				proxy_pass http://127.0.0.1:8000;
			}
       }
	   - sudo ln -s /etc/nginx/sites-available/artificial-teacher-backend /etc/nginx/sites-enabled/artificial-teacher-backend -> Crear enlace simbolico
	   
- sudo systemctl restart nginx.service (sudo service nginx restart) -> Reiniciar nginx

######### CONFIGURAR SERVIDOR SISTEMA (UBUNTU) ###########

- sudo nano /etc/systemd/system/artificial-teacher-backend-uvicorn.service -> Crear servicio sistema para mantenerlo arrancado

1 )
	[Unit]
	Description=FastApi Backend

	[Service]
	WorkingDirectory=/root/project/fastapi-backend
	Environment="PATH=/root/project/env/bin"
	ExecStart=/root/project/env/bin/gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app

2) (usado actualmente)

	[Unit]
	Description=Artificial Teacher Backend

	[Service]
	WorkingDirectory=/root/project/artificial-teacher-backend
	Environment="PATH=/root/project/env/bin"
	ExecStart=/root/project/env/bin/uvicorn main:app --reload

	[Install]
	WantedBy=multi-user.target

- sudo systemctl start artificial-teacher-backend-uvicorn -> Arrancar servicio creado
- sudo systemctl status artificial-teacher-backend-uvicorn -> Ver status
- sudo systemctl disable artificial-teacher-backend-uvicorn -> Deshabilitar servicio


######### CONFIGURAR FIREWALL (UBUNTU) ###########

- Links:
	- https://www.digitalocean.com/community/tutorials/how-to-set-up-a-firewall-with-ufw-on-ubuntu-22-04
	- https://www.digitalocean.com/community/tutorials/initial-server-setup-with-ubuntu-20-04

- Proceso

	- sudo ufw default deny incoming -> Negar todas las peticiones entrantes (mas seguro)
	- sudo ufw default allow outgoing -> Permitir todas peticiones salientes

	Añadir protocolos tcp:

		1) Usando app profiles -> sudo ufw app list
			- sudo ufw allow 'OpenSSH' -> Necesaria para mantener conexion ssh remota
			- sudo ufw allow 'Nginx HTTP' -> Necesaria para recibir peticiones http (para eliminar sudo ufw delete allow 'Nginx HTTP')
			- sudo ufw allow 'Nginx HTTPS' -> Necesaria para recibir peticiones https
			- sudo ufw allow 'Nginx Full' -> Necesaria para recibir peticiones http/https
			
		2) Usando protocolos directamente
			- sudo ufw allow ssh
			- sudo ufw allow http
			- sudo ufw allow https (para eliminar sudo ufw delete allow https)
